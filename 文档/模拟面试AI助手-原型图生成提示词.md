# 模拟面试AI助手 - 原型图生成提示词

> 用途：复制下面整段内容，粘贴到设计创意类 AI 工具（MasterGo AI / 即时设计 AI / 墨刀 AI / Figma AI 等）中生成高保真原型图。
>
> 使用方法：
> - 如果工具支持"整套生成"，直接复制第一部分【整体说明】+ 全部 9 个页面描述
> - 如果工具一次只能生成 1 页，就分 9 次，每次复制【整体说明】+ 对应那一页的描述

## 第一部分：整体说明（每次生成都要带上）

```
角色：你是一名资深 UI 设计师，擅长为校招类教育产品做高保真视觉设计。

项目：模拟面试 AI 助手 Web 网站，电脑端浏览器（1440px 宽屏）

目标用户：计算机/软件相关专业应届毕业生，准备参加 2026 届秋招

设计风格：
- 风格定位：流光凝彩——去灰、有透光感、柔润不刺眼，用三色晕染渐变营造层次感，每个模块色彩丰富有设计感，整体高级
- 主色调（按使用频率）：暖珊瑚 #FF8E7B、碧松石 #3CCDB6、蜜金 #F5C950、藤萝紫 #B49EE8、樱花粉 #F2A0B6、嫩芽绿 #5CD9A0、晴空蓝 #6BAEEA、琥珀橙 #F5A86A
- 辅助色：文字 #3D3848、次级文字 #82789A、描边线 #E8E3DC
- 字体：中文用思源黑体 / 苹方，英文用 Inter
- 渐变风格（重要）：所有按钮、卡片头、数据卡片的渐变都采用"三色晕染渐变"——起始色 → 中间过渡色（更浅更亮的同色系）→ 结束色，形成透光般的柔和过渡。中间过渡色参考：珊瑚用 #FFB4A0、松石用 #7DE5D2、藤紫用 #D4C8F0、蜜橙用 #FFD6B0
- 背景风格（重要）：页面背景是动态光圈背景——不是纯白也不是简单渐变，而是大面积柔光圆环重叠形成的"光圈"效果。五个大尺寸圆形 radial-gradient 叠加：左上珊瑚光圈（rgba(255,142,123,0.25)）、右上松石光圈（rgba(60,205,182,0.22)）、左下藤紫光圈（rgba(180,158,232,0.20)）、右下蜜金光圈（rgba(245,201,80,0.18)）、中部粉色氛围光（rgba(242,160,182,0.10)），每个光圈半径 700-1000px，透明度 18%-25%，能清楚看到圆形光晕。基底是 135° 淡彩渐变（#FFFAF4 → #F0FAF7 → #F4F1FC → #FCF4F6），background-attachment:fixed 固定不随滚动。光圈之上叠加动态元素（如果工具支持动效/微动效）：3-6 颗流星沿左下方向缓慢划过（细长渐隐光带，白色发光头部 + 珊瑚/松石/藤紫/蜜金彩色尾迹，透明度 60%-85%，每 5-8 秒一颗、错开出现），若干彩色星点（4px 圆点 + 柔和辉光，缓慢闪烁），光晕本身缓慢漂移呼吸，营造"夜空许愿"般的灵动感
- 卡片风格：圆角 12px，微透明白底（白色 88% 不透明度，带轻微毛玻璃感），双层柔和阴影（近阴影 rgba(140,110,170,0.06) + 远阴影 rgba(140,110,170,0.05)），高级有质感
- 导航栏：半透明白色（75% 不透明度）+ 毛玻璃模糊效果，下边框为半透明白线
- 整体感觉：像一个为年轻人设计的高级练习工具，背景有大面积彩色光圈渲染、好看有设计感，内容卡片像浮在光环上，色彩去灰有透光感但不刺眼

整体规范：
- 所有页面顶部导航栏固定（半透明毛玻璃质感），仅登录页不显示
- 每个页面要有清晰的标题区（大标题 + 副标题）
- 卡片统一圆角 12px、微透明白底、双层柔和紫调阴影
- 重要按钮用暖珊瑚三色晕染渐变（#FF8E7B → #FFB4A0 → #F2A0B6），次要按钮用微透明白底描边
- 数据卡片每张用不同色系的三色晕染渐变，避免单调
- 留白充足，1440px 宽屏下内容居中、最大宽度 1200px
- 不要出现具体真实的人名/电话/邮箱（用"王同学""138****8888"等占位）
```

## 使用技巧

| 情况 | 怎么做 |
|---|---|
| 工具支持整套生成 | 复制【整体说明】+ 全部 9 段，一次粘贴 |
| 工具一次只生成一页 | 每次复制【整体说明】+ 单个页面段落，分 9 次 |
| 生成效果不理想 | 在提示词末尾追加"请更偏向流光凝彩配色（去灰有透光感）、加大圆角和三色晕染渐变，背景要有大面积圆形光圈重叠渲染效果，并叠加流星划过轨迹和闪烁星点装饰，不要纯白" |
| 要生成会员中心 | 单独复制【整体说明】+ 页面 9，并强调"套餐卡片要有价格对比和推荐角标" |
| 想要手机版 | 把"1440px 宽屏"改成"375px 手机竖屏"，导航栏描述改成"底部 Tab 栏" |
